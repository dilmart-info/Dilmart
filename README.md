# متجر ديل مارت| DilMart Store

متجر **DilMart Store** (متجر ستايلي) هو منصة تجارة إلكترونية مستقلة متعددة البائعين (Multi-vendor marketplace) مخصصة للسوق العراقي، توفر أدوات متكاملة للتجار والمسؤولين لإدارة المنتجات، الطلبات، التوصيل، والتسويات المالية.

> [!IMPORTANT]
> متجر **DilMart Store** مستقل تماماً عن منصة حجوزات وصالونات DilMart (DilMart booking/barber platform). التكامل الوحيد حالياً هو على مستوى التحقق من الهوية وصلاحيات المستخدمين (Authentication/Identity).

## المميزات

- منصة متعددة البائعين (Multi-vendor) تدعم عزل بيانات التجار وإدارتها بشكل كامل.
- واجهة مستخدم حديثة وسهلة الاستخدام باللغة العربية للزبائن، التجار، والمسؤولين.
- الدفع عند الاستلام (COD) مع ربط مباشر ومؤتمت مع خدمات التوصيل (Jenni).
- لوحة تحكم إدارية شاملة للمسؤولين (Admin Panel) لمراقبة العمليات المالية والتسويات.
- متوافق بالكامل مع الأجهزة المحمولة ومتصفحات الويب.
- نظام كوبونات خصم متطور وإدارة مرنة للمخزون والمنتجات.

## التقنيات المستخدمة

- **Frontend**: React + Vite + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Backend/Database**: Supabase
- **State Management**: Zustand
- **Charts**: Recharts

## التشغيل المحلي

قم باتباع الخطوات التالية لتشغيل المشروع على جهازك:

1. قم بتثبيت التبعيات:
   ```sh
   npm install
   ```
2. قم بتشغيل خادم التطوير:
   ```sh
   npm run dev
   ```

## لوحة التحكم (Admin)

يمكن الوصول للوحة التحكم عبر الرابط `/admin/login`. يتطلب الدخول حساباً بصلاحية مسؤول (Admin).
