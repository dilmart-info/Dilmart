Readable preview tiles: `review/FIX_PREVIEW_CONTACT_SHEET_01.png`

Columns conceptually shown:

- proposed image (or HOLD marker)
- SKU
- current identity
- proposed identity
- current size → proposed size
- source confidence
- decision status
