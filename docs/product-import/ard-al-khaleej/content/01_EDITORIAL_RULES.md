# 01 — Editorial Rules

Source: `DilMart_ARD_AL_KHALEEJ_GOLDEN10_CONTENT_v1.xlsx` → sheet `EDITORIAL_RULES`

## Short description (`short_description`)

- Required for every **new** product and every **new import** row.
- Arabic, clear; mention type, brand, size, and general character only.
- Editorial target: **90–180** characters.
- Hard validation: **40–280** after trim.
- No HTML. Whitespace-only rejected.

## Detailed description (`description`)

- Optional.
- Write only from a trusted source (notes, usage, gender when official).
- Never auto-copy to/from `short_description`.

## Source priority

1. Official manufacturer
2. Official brand catalog
3. Official distributor
4. Trusted retailer only if none above — tag clearly

Do **not** rely on blogs, anonymous marketplaces, Fragrantica-first, user reviews, or AI invention.

## Forbidden claims without proof

Duration in hours, projection, “100% original”, “best”, clone of a global fragrance, guaranteed performance, gender without official evidence, country of origin without evidence.
