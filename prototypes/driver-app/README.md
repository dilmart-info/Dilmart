# DilMart Driver development application

Isolated synthetic Driver application for local and Android debug use. It is not the customer app and it is not a production Driver release.

```text
node prototypes/driver-app/serve.mjs
```

Open `http://127.0.0.1:4175/`.

Synthetic phone `07701234567` and code `482196`. Device approval and server results are under أدوات التطوير, or the dashed development control on pending screens. Nothing is stored and no production service is called.

Android debug id: `com.dilmart.driver.dev`. Do not use the customer id `com.dilmart.store`.
