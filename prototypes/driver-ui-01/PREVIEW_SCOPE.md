# DRIVER-UI-01 preview scope

This directory is a mock-only interactive preview of 14 DilMart Driver frames. It is not the production H2 package.

Allowed: synthetic Arabic fixtures, simulated screen transitions, light and dark appearance.

Not allowed here: production authentication, network calls, GPS, camera, push, scanner hardware, external navigation, Supabase, credentials, customer data, persistence of business events, or a native stack decision.

G0, ED-01, D09, and UX-09 stay open. V2 production implementation stays not authorized.
