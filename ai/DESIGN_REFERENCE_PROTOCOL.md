# DESIGN_REFERENCE_PROTOCOL.md — DilMart-Store

When the user provides screenshots from Ozon, Noon, Shopify stores, cosmetics stores, salon suppliers, or competitors, follow this protocol:

1. Identify the design pattern, not the exact copyrighted design.
2. Extract structure: spacing, hierarchy, CTA placement, image treatment, card density.
3. Adapt to DilMart-Store brand and Arabic RTL.
4. Preserve existing components and API contracts.
5. Do not copy logos, proprietary icons, exact visual identity, or copyrighted assets.
6. For each redesign, state:
   - which screen/section changed
   - what UX problem it solves
   - what remains out of scope

For marketplace home/category/product sections, prioritize:

- clarity of product discovery
- trust
- speed
- mobile shopping behavior
- separation between header/hero/content
- premium but not heavy visuals
