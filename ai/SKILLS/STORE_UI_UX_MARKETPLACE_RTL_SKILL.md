# Skill: Arabic Marketplace UI/UX RTL — DilMart-Store

## Mission

Create a premium, fast, Arabic-first shopping experience without damaging operational correctness.

## Use When

- homepage redesign
- product/category/store pages
- cart/checkout UX
- admin/merchant UI polish
- mobile responsiveness
- visual QA

## Design Priorities

1. Mobile shopping clarity.
2. Trust and professionalism.
3. Strong product imagery.
4. Clear price/discount/availability.
5. Simple checkout.
6. Admin/Merchant operational clarity.

## Rules

- Preserve API contracts.
- Do not add fake data flows.
- Do not hide error states.
- Do not hardcode product/business data unless clearly demo-only.
- Use existing design system/components when possible.
- Keep RTL correct.
- Avoid heavy animation in checkout/admin pages.

## Marketplace Sections Worth Improving

- hero with dark image overlay and clear logo contrast.
- category chips/cards.
- featured merchant/product carousel.
- offer blocks.
- trust badges: COD, fast delivery, verified merchants.
- product cards with quick add where safe.
- empty states for cart/wishlist/search.
