# VISUAL_QA_GATE.md — DilMart-Store

## Required Visual QA Checklist

For any UI change, verify:

- [ ] RTL layout is correct.
- [ ] Mobile view works at 360px width.
- [ ] No horizontal scrolling.
- [ ] Primary CTA is visible.
- [ ] Long Arabic copy does not break layout.
- [ ] Loading state exists where data is fetched.
- [ ] Empty state exists.
- [ ] Error state exists.
- [ ] Images have fallback behavior.
- [ ] Buttons are accessible and not too small on mobile.
- [ ] Status badges are understandable without relying only on color.
- [ ] Admin/Merchant tables remain usable.
- [ ] No console errors from the changed screen.

## Marketplace-Specific Screens

Extra review for:

- Home hero.
- Product listing.
- Product details.
- Cart.
- Checkout.
- Store page.
- Admin order detail.
- Merchant order detail.
- Finance/settlement pages.
