## auth:guard false positive
src/integrations/supabase/client.ts is unmodified and correctly uses `storage: authStorage`.
The guard flags line 12, which is a comment that quotes the forbidden pattern:
  // and is owned by @/lib/auth/auth-storage. Never hardcode `storage: localStorage`.
stripComments() removes line comments with /\/\/.*$/, but this worktree has CRLF line
endings, so after split("\n") every line still ends with \r. In JavaScript `.` does not
match \r, so $ never anchors and the comment survives stripping.
On a LF checkout — which is what GitHub Actions uses — the guard passes. Neither the guard
nor the client file was touched by this task; both last changed in a95df07.
