## Android 12+ note (platform constraint, not a defect in this change)
Capacitor 8 calls androidx core-splashscreen installSplashScreen() on every API level and only
falls back to the legacy ImageView splash if that call throws. On API 31+ the platform draws the
system splash from the theme: windowSplashScreenBackground plus a centre-masked
windowSplashScreenAnimatedIcon. The platform clips that icon to a circle, so a 3:1 wordmark
cannot be shown there. The launch screen therefore shows the brand background with the brand app
icon. The full logo lockup from assets/logo.png is what ships in every drawable*/splash.png (the
legacy fallback path) and in the iOS Splash.imageset, where LaunchScreen.storyboard renders it in
full.
